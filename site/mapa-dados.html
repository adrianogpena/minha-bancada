Mapa dos dados

Cada fonte oficial publica sua parte, quase nunca com o mesmo código. Aqui estão todas as ligações que o site faz entre elas, sem citar ninguém, para você entender de onde vem o que aparece em cada página.

Como uma ligação é feita

  • Pela própria fonte: o código vem pronto (número da proposição, CNPJ, sequencial do TSE). Não há dúvida.
  • Pelo nome: quando a fonte só traz o nome. A ligação tem confiança alta, média ou baixa, conforme o que foi comparado (nome civil, nascimento, cargo, UF, nome de urna).
  • Nome ambíguo não é ligado. Se mais de uma pessoa serve, o registro fica sem ligação em vez de apontar para a pessoa errada.
  • Uma correção à mão só existe num arquivo público do repositório, nunca escondida no código.

O que fica sem ligação

Registro sem par seguro continua visível na fonte, mas sem apontar para uma pessoa: autores que não são deputados, nomes repetidos, pessoas que as fontes escrevem de formas muito diferentes. A tabela de ligações do projeto guarda, para cada fonte, quantos registros foram ligados, por qual método, quantos ficaram ambíguos e quantos sem par.

Cada dado de político traz o link da fonte. Para a lista de fontes e o estado das APIs, veja Sobre os dados.
